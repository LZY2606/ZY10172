# 持时破裂谱 — 蠕变持久断裂寿命主曲线工作台

本地单机 Web 服务：用不同温度、应力、炉次的持久试验数据拟合**蠕变断裂寿命主曲线**，
严格区分已断裂样本、**到时未断的右删失样本**与**中途变更载荷的变载样本**。

- 技术栈：Rust + Axum + SQLite（`rusqlite` 捆绑编译，无需本机 sqlite）+ 原生 HTML/JS
- 模型：Larson–Miller（受限参数）或自定义受限二次多项式
- 层级炉次偏置、删失感知极大似然、Robinson 线性累积损伤、外推距离/风险/杠杆度审计

## 安装与运行

```bash
cargo fetch --locked
cargo test --locked && cargo run --locked -- --listen 127.0.0.1:5512
# 浏览器访问 http://127.0.0.1:5512 ，页面标题为「持时破裂谱」
```

可选参数：`--db <sqlite 文件>`（默认 `rupture.db`）、`--no-seed`（空库不自动种入 fixture）。

## 固定 fixture

`fixtures/samples.json` 由 `scripts/gen_fixture.py` 用**确定性随机数**生成，可随时复算：

```bash
python3 scripts/gen_fixture.py
```

数据包共 27 个试样，同一温度跨 HA / HB 两个炉次：

| 类别 | 数量 | 说明 |
| --- | --- | --- |
| `rupture` 已断裂 | 14 | 450–650 °C、50–300 MPa |
| `rupture` 右删失 | 5 | 到截止时间仍未断，`time_h` **只是寿命下界** |
| `strain2pct`（2% 应变准则） | 6 | 独立失效准则，**永不与 rupture 混拟** |
| `rupture` 变载 | 2 | 分段载荷；仅在选定累积损伤模型时参与拟合 |

生成所用真值（仅供复核拟合还原度）：Larson–Miller
`T_k·(20 + log10 t) = -3000 + 46·σ + 4800·log10 t`，炉次偏置 HA=0、HB=−0.12 dex，噪声 σ=0.10 dex。

## 数据口径（不可妥协的规则）

1. **绝对温度换算在入库时校验**：每条记录必须显式给出 `temp_unit`（`C` 或 `K`）。
   缺单位、单位无法识别、或数值落在不合理区间，整条数据拒绝入库——不在摄氏度/开尔文之间猜测。
2. **右删失只给下界**：`status=censored` 表示“到 `time_h` 尚未断裂”，似然用
   `P(T > time_h)`，**不会**把它当作在截止时刻恰好断裂，也不产生点残差，只产生删失 NLL 贡献。
3. **变载样本默认不拟合**：未选定累积损伤模型时，变载样本出现在“排除”列表并注明原因；
   启用后按 Robinson 线性累积损伤 `D = Σ tᵢ / t_r(Tᵢ,σᵢ)` 纳入，断裂对 `D=1` 取点似然、删失对 `D<1` 取尾概率。
4. **失效准则不混组**：拟合必须指定 `criterion`；`rupture` 与 `strain2pct` 绝不进入同一次拟合，
   跨准则对比返回 400。

## 模型与拟合

- **Larson–Miller**：`T_k·(C+y)=b0+b1·σ+b2·y`，即 `y=(T_k·C−b0−b1σ)/(b2−T_k)`，`y=log10 t`。
  `C=20` 固定；`b2` 经 softplus 约束为 `b2 > Tmax+50 K`，杜绝分母穿越零造成的病态。
- **自定义受限多项式**：`y=b0+b1·sₙ+b2·sₙ²+b3·Tₙ+b4·Tₙ²`，
  `b2,b4 ≤ 0`（softplus 约束），防止包络外开口向上的病态发散。
- **层级炉次偏置**：参考炉次固定为 0；其余炉次偏置 δ 带高斯收缩先验（默认 τ=0.3 dex），
  也可在请求里用 `fixed_heats` 给定固定值。
- 拟合输出：物理参数及标准误、炉次偏置、σ、残差、**逐样本删失 NLL 贡献**、纳入/排除清单、AIC/BIC。

### 允许外推范围

拟合时必须指定允许外推的温度/应力窗口。预测点：

- 在窗口**之外** → 明确**拒绝**，不返回曲线延长值（`risk=rejected`）；
- 在窗口内但实验包络之外 → 必须同时给出：
  - 归一化包络**距离**（温度、应力各自按包络极差归一后取欧氏范数）
  - **95%（可调）预测区间**与中位寿命
  - **边界活跃**标记（命中 temp_min/temp_max/stress_min/stress_max 哪条边）
  - **外推杠杆度**（参数方差 / 噪声方差）
  - **风险等级**：`low`（距离≤0.1）/ `medium`（≤0.4）/ `high`（更大），不用平滑曲线掩盖不确定性。

## 运行记录导出与重放复核

- `GET /api/export` 导出 bundle：原始样本（含温度单位）+ 每次拟合的配置 + 拟合结果。
- `POST /api/replay`（body 为导出的 bundle）会**清空数据库 → 重新导入样本（再次经过单位/口径校验）
  → 按原配置逐条重拟合**，返回每次的纳入集合与指标，用于清空后的复核。
- `POST /api/reset` 清空样本/拟合/审计表；空库重启会自动重新种入固定 fixture。
- 所有导入、拟合、清空、重放动作写入 `audit_log`，可在“数据与重放”页查看。

## 主要 HTTP 接口

| 方法/路径 | 作用 |
| --- | --- |
| `GET /api/samples` `POST /api/import` | 列出/导入样本（入库即做单位与口径校验） |
| `POST /api/fits` `GET /api/fits/:id` | 拟合/查看拟合（参数、残差、删失贡献、纳入清单） |
| `POST /api/predict` | 寿命预测 + 外推距离/区间/边界/风险 |
| `GET /api/compare?a=&b=` | 两个模型在同一样本上的逐样本对比（跨准则 400） |
| `GET /api/export` `POST /api/replay` `POST /api/reset` | 导出 / 重放复核 / 清空 |
| `GET /api/audit` | 审计日志 |

## 自动化测试

`tests/end_to_end.rs` 会启动真实 HTTP 服务做黑盒验收，覆盖：标题与 fixture、
右删失不被当作断裂、损伤模型开关造成的样本集合差异、失效准则隔离、温度单位强制校验、
外推距离/区间/边界/拒绝、跨准则对比拦截、以及“导出→清空→重放”复算闭环。
