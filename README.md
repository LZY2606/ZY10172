# 持时破裂谱 · 蠕变持久主曲线工作台

本地运行的蠕变持久（蠕变断裂）寿命主曲线工作台。材料团队用不同温度、应力和炉次的
持久试验推导断裂寿命，本工作台对 **已断裂 / 右删失（到时未断）/ 中途变更载荷（变载）**
三类试样做口径正确的统计建模，并在同一样本集合上比较两种模型形式。

- 后端：Rust + Axum（SQL 持久化：SQLite，`rusqlite/bundled`，无需系统 sqlite）
- 前端：单文件原生 HTML/JS/Canvas（随二进制内嵌）
- 数据：随仓库交付的固定 fixture（`data/fixtures.json`，24 个试样）
- 测试：`tests/api.rs` 端到端覆盖验收要点

## 安装与演示

```bash
cargo fetch --locked
cargo test --locked
cargo run --locked -- --listen 127.0.0.1:5512
# 浏览器访问 http://127.0.0.1:5512，应看到标题「持时破裂谱」
```

首次启动若数据库文件不存在，会自动导入内置 fixture 并在控制台打印导入数量；
之后可用页面上的「清空数据库」→「载入固定 fixture」按钮复核重放。

可选参数：`--db <path>`（默认 `./mastercurve.db`）。

## 数据口径（务必先读）

1. **温度必须显式带单位**。入库字段 `temp_unit` 只接受 `"C"`（摄氏度）或 `"K"`（开尔文）。
   缺单位、空单位或其他写法一律拒收，**不会因为缺单位而猜测**；段温度同理。
2. **右删失 ≠ 在截止时刻断裂**。`outcome="censored"` 表示“截止时间仍未断裂”，
   寿命只有下界 `T > t_stop`。似然只使用存活概率 `P(T > t_stop)=Φ(z)`，
   残差表中不为删失样本伪造点残差，只报告截止时的存活概率与对数似然贡献。
3. **变载样本必须选定累积损伤模型才参与拟合**。启用 Robinson 线性累积损伤
   `D = Σ dur_k / tf_k` 后：断裂变载样本取 `D=1`；右删失变载样本取 `D<1`（只给下界）。
   未启用损伤模型时，所有 `variable=true` 试样显式排除并在“样本纳入”表给出原因。
   单段 tf 为对数正态，D 的尺度用一阶 delta 近似。
4. **不同失效准则不混为一组**。`criterion` 不同的试样（如 `rupture` 与 `strain_1pct`）
   永远不会进入同一次拟合；模型比较接口也会拒绝准则不同或纳入集合不同的两次运行。
5. **炉次层级偏置**。每组第一个（字典序）炉次为基准，偏移固定为 0；其余炉次为
   log10(寿命) 加性偏移，带岭收缩 `λ·b²`（λ 可在页面配置，默认 1.0）。
6. **外推必须诚实**。预测结果区分：实验包络内 / 允许范围内的包络外 / 超出允许范围（拒绝）。
   包络外点强制显示到包络的温度/应力距离、归一化距离、95% 预测区间、非线性杠杆度、
   风险等级（low/medium/high）与“边界活跃”说明；图上用虚线/橙色表示允许外推，
   红色 × 表示拒绝外推，绝不用主曲线延长线掩盖外推事实。
   允许外推范围由请求中的 `min/max_temp_c`、`min/max_stress_mpa` 显式给出，
   缺省等于实验包络（即默认不允许任何外推）。

## 模型

寿命分布：`y = log10(tf/h) ~ Normal(μ, τ²)`，τ 与主参数一起做极大似然估计。

- **LM（Larson-Miller）**：`P = T·(C + log10 tf) = a0 + a1·σ + a2·σ²`，
  即 `μ = (a0 + a1σ + a2σ²)/T − C + b_heat`。σ 为原始应力 MPa。
  受限参数范围：C∈[0,60]，a0∈[10000,30000]，a1∈[−30,30]，a2∈[0,0.05]。
- **CX（自定义受限形式）**：`μ = β + γ·x + (q/2)·x² + α/T + b_heat`，
  x = log10(σ/MPa)。q∈[−0.5,0.5] 等参数均带箱约束；
  数据范围不足以辨识 q 时它会贴边，并在结果 `warnings` 与参数表中标记“边界约束活跃”。

有界参数在优化器内部以 logistic 映射为无界变量，τ 以 log 形式参与；
优化用自适应 Nelder–Mead（两组初值），标准误由观测信息矩阵（数值 Hessian）给出，
奇异时自动岭加载并告警。预测区间同时包含参数不确定性（delta 方法）、
残差散布 τ²，以及对未见炉次的炉次间方差。

## 固定 fixture（`data/fixtures.json`，24 个试样）

- 14 个断裂（rupture）恒载试样：500/550/600 °C × 多档应力，跨炉次 A、B。
- 4 个 rupture 右删失恒载试样（C01–C04）。
- 3 个变载试样：V01、V02 为变载后断裂；V03 为变载后到时未断（右删失，D≈0.875）。
- 3 个 `strain_1pct`（1% 蠕变应变）断裂试样 S01–S03，用于验证“不混组”。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 操作页面 |
| GET | `/api/specimens` | 列出全部试样（含已换算开尔文与段明细） |
| POST | `/api/specimens` | 批量导入，逐条校验；返回 imported / skipped_duplicate / rejected |
| POST | `/api/specimens/clear` | 清空试样与导入批次（保留运行记录） |
| POST | `/api/fixtures/load` | （重新）导入内置固定 fixture，幂等 |
| POST | `/api/fit` | 拟合+预测，结果同时落库为一次运行 |
| GET | `/api/runs` | 历史运行（请求与结果） |
| GET | `/api/runs/export` | 导出试样、导入批次与全部运行（JSON，可重放复核） |
| POST | `/api/compare` | 两次运行的 AIC 比较（强制同准则、同样本集合） |
| GET | `/api/imports` | 导入批次记录 |

## 清空后重新导入复核

```bash
curl -s -X POST http://127.0.0.1:5512/api/specimens/clear
curl -s http://127.0.0.1:5512/api/specimens        # 应为 {"specimens":[]}
curl -s -X POST http://127.0.0.1:5512/api/fixtures/load
# 或直接删除 mastercurve.db* 后重启，等价于首次启动自动导入
```

## 验收要点对照

- 启用 vs 禁用损伤模型：纳入数分别为 21（含 V01–V03）与 18（变载全排除）。
- 包络外预测（如 625 °C/50 MPa）：给出距离 25 °C、95% 区间与杠杆度，风险 high 但允许；
  超允许范围点（650 °C/30 MPa）返回 `allowed=false`、`blocked_by` 与活跃边界列表。
- 模型比较：同集合 LM/CX 返回 ΔAIC 与偏好；集合不同（损伤开关不同）返回 400。
